# 0012: Readable frosted glass surfaces

Date: 2026-10-02. Accepted for the owner-requested glass polish.

Keep the existing Windows acrylic implementation and deferred material lifecycle.
Increase text-bearing panel and card tint so busy desktop colors interfere less
with labels. Use restrained cool-neutral shell gradients and a directional,
subtle rim to separate surfaces without adding blur passes or animation.
Strengthen secondary text colors in both themes. Preserve opaque transparency-off
fallbacks, system high-contrast resources, reduced-motion behavior and all features.

This is a palette refinement, not a taskbar change. No Windows settings change.
Actual DWM transparency and contrast over real desktops still require live visual
acceptance; compilation and offscreen captures alone do not prove that result.
